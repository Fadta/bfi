This is a brainfuck interpreter. A simple project to learn about interpreters and architecture.

# Compilation

`gcc bfi.c -o bfi.out`


# Use

`bfi [bf file path]`


# Example

`bfi ./demos/fibo.bf`


# Included demos

helloworld.bf: classic "Hello World"
cat.bf: echoes introduced output
fibo.bf: Fibonacci sequence, must Ctrl+C to end
